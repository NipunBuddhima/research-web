Valuer Bot

Blockchain-Enabled Automated Rating Valuation System for Sri Lanka

This project proposes an integrated municipal rating valuation platform that combines GIS-based spatial analysis, deep learning feature recognition, and blockchain integrity validation. The goal is to reduce manual inefficiencies and improve transparency, consistency, and governance compliance in property valuation workflows.

Project Snapshot

  • GIS Accessibility Tracking Automated Valuation Engine
  • Street and image-based feature extraction
  • Cryptographic hashing and on-chain verification
  • Automated valuation with reduced manual dependency

Literature Survey

Existing studies in GIS-based valuation, deep learning-based land feature detection, and blockchain-enabled governance show strong isolated benefits. However, most works do not integrate all three into one municipal valuation pipeline tailored to Sri Lankan rating practices.

Research Gap

No comprehensive framework currently combines accessibility-based valuation, AI-driven internal feature adjustments, and immutable transaction verification for statutory-compliant municipal rating value assessment.

Research Problem

Traditional valuation in municipal councils is labor-intensive and vulnerable to inconsistency, manipulation, and delayed updates. A transparent, automated, and scalable system is required to support trustworthy public-sector valuation and taxation decisions.

Research Objectives

  • Model land value using GIS accessibility and comparative factors
  • Detect internal property features from street/satellite imagery using CNN models
  • Compute statutory valuation components automatically
  • Guarantee integrity via hash verification and blockchain-backed smart contracts

Methodology

The proposed methodology would involve employing the concept of blockchain technology to determine the data validity aspect, GIS technology to assess the worth of the space involved, and the application of machine learning to establish features in designing the system. This process would entail the involvement of several levels where the user interface and regression analysis form part of the back end.

Technologies Used

  • GIS: QGIS, OpenStreetMap data, accessibility modeling
  • AI/ML: TensorFlow, Keras, CNN-based image classification
  • Backend: FastAPI, Node.js, Express.js
  • Web Layer: React.js, Next.js
  • Blockchain: Hardhat, Solidity, ethers.js, PoA-based permissioned network
